# Hero Photography Asset

To use a photographic Hero background, add a locally authorised JPEG at:

`assets/hero_children_learning.jpg`

Recommended content: a distant, natural-light group of 3–6-year-old children
engaged in collaborative learning or constructive play in a contemporary
preschool setting. Children should not face the camera. Avoid logos, readable
personal information, classroom identifiers, and recognisable real children
unless the required consent and reuse permission are documented.

The Streamlit application detects this file automatically and applies a
research-first dark-green overlay for readable central typography.

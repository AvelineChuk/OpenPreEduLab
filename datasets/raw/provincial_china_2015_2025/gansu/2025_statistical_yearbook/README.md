# Gansu Statistical Yearbook 2025

This directory contains an unmodified ZIP downloaded on 2026-08-06 through a
normal browser session from the Gansu Provincial Bureau of Statistics official
yearbook page. The browser download was completed before the SHA-256 value in
`manifest.csv` was calculated.

Official index page:
`https://tjj.gansu.gov.cn/tjj/c109464/info_disp.shtml`

The official 2025 usage page identifies this publication as *Gansu Statistical
Yearbook 2025* and describes its web-reading and spreadsheet-download contents:
`https://tjj.gansu.gov.cn/c117468/202511/174241977.shtml`

The archive contains 898 entries. Its index lists the following potentially
relevant source tables for 2024:

- `zk/html/18-01.xls`: schools, staff, and reported full-time teachers;
- `zk/html/18-02.xls`: students in all school types;
- `zk/html/18-25.xls`: basic conditions of kindergartens and primary schools
  by locality and county.

These entries are only identified as raw-source candidates. No values have
been transcribed to staging and no variable has been approved for analytical
use. In particular, the archive's population age-structure table `02-04.xls`
uses the broad groups `0-14`, `15-64`, and `65 and over`; it is not a strict
3-5 or 3-6 preschool-age denominator. Reported `full-time teacher` counts also
require the project's existing FTE-definition review before any model use.

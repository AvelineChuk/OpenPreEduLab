# Provincial China Panel: Raw Archive

This directory is reserved for original, unmodified source files used to construct the first real-data panel for 31 provincial-level regions in China from 2015 to 2025.

Only files with a registered source, retrieval date, geographic level, reference period, reuse status, and SHA-256 checksum may be added. National aggregate publications must not be copied into this directory as substitutes for provincial observations.

No raw source is treated as model-ready data. Extraction occurs only in `datasets/staging/`, and approved harmonised fields are written to `datasets/processed/`.

# Raw Source Archive

This directory preserves downloaded source files before extraction or transformation. Raw files must remain unchanged after acquisition.

The first verified source family is the Ministry of Education's National Education Development Statistical Bulletin series, recorded in `../source_registry.csv`. These publications are relevant to preschool education trends and variable definitions, but are national aggregates and must not be used as city-level PRAI observations.

Each future raw source should be saved with a stable source identifier and retrieval date. Its metadata should record the original URL, publisher, access date, geographic level, time period, file format, and SHA-256 checksum.

# Official Government Republication Evidence

This directory contains the two XLS attachments downloaded from the official Xinxing County Finance Bureau republication of the notice:

> Ministry of Finance and Ministry of Education Notice on Issuing the 2026 Support for Preschool Education Development Fund Budget

**Republication page:** `https://www.xinxing.gov.cn/yfxxczj/gkmlpt/content/2/2014/mpost_2014320.html`  
**Document number:** `Caijiao [2026] No. 68`  
**Stated document date:** 10 April 2026  
**Republication page date:** 29 May 2026  
**Page source attribution:** Ministry of Finance and Guangdong Provincial Department of Finance

The local user-supplied XLS files have different binary SHA-256 values from the republished attachments. A hidden, read-only Excel comparison found identical sheet names, used ranges, and all visible cell values in both file pairs. Both versions are retained; no file has been overwritten. This establishes official-government-republication support for the visible content, while the original central-government publication URL remains to be located.

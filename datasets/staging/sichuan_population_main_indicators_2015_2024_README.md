# Sichuan Population Context: Staging Record

This staging table is a manual transcription of the provincial series in Table 3-1 of the 2025 Sichuan Statistical Yearbook. It retains resident population, urbanization, birth, death, and natural-growth indicators for 2015–2024.

The table does not report preschool-age population. It may support descriptive population-trend context or later forecast design after review, but it is not eligible for the PRAI educational-demand denominator. The source notes indicate census-based values for 2000, 2010, and 2020 and annual survey-based estimates for other years; the 2020–2021 boundary is therefore flagged and retained without adjustment.

# Beijing Population and Education-Finance Context: Staging Record

This table separately preserves two broad contextual series from the 2025 Beijing Statistical Yearbook: resident population aged 0–14 (in ten thousand persons) and all-level education expenditure (in ten thousand yuan). It is not a Preschool Resource Allocation Index input table.

The age series does not identify the preschool-age population, while the expenditure table is an aggregate education series rather than preschool-specific public expenditure. Neither series may be substituted for the PRAI demand denominator or financial-resource indicator without an explicit, source-supported mapping decision.

The source notes identify a census and sampling-method boundary around 2020–2021. These values are retained and flagged for review rather than adjusted. All entries require an independent second review before any downstream use.

# Shanghai Population and Fiscal Context: Staging Records

These records are a source-faithful transcription from Tables 2.1 and 4.1 of the 2025 Shanghai Statistical Yearbook. The raw archive retains each official frame page, header page, and main-value page because the yearbook serves these components separately.

The population record reports total resident population and registered-population context. It does not provide a preschool-age denominator. The fiscal record reports general public-budget aggregates and is not preschool-specific public expenditure. Neither file may be directly mapped to a PRAI demand or financial indicator.

All entries require independent second review. The population series flags the 2020–2021 boundary for methodological review and does not adjust reported values.

# Guangdong Kindergarten Statistics: Staging Record

This staging table records the kindergarten fields visibly published in the 2025 Guangdong Statistical Yearbook, Table 19-3 Continued. The original full yearbook archive is retained at:

`datasets/raw/provincial_china_2015_2025/guangdong/2025_statistical_yearbook/Guangdong_Statistical_Yearbook_2025.zip`

The source table reports 2000, 2005, 2010, 2015, 2022, 2023, and 2024. Only the years inside the proposed 2015–2025 panel are entered. No values are created for unreported years.

The table identifies `在园幼儿数` as children in kindergartens and is provisionally mapped to `enrolled_children` after unit conversion. The full-time teacher count remains a source-faithful field and is not automatically treated as FTE.

The corresponding Excel entry, `directory/19/excel/19-03-1.xls`, was independently read directly from the retained original ZIP. The four staging records match the Excel values after the documented ten-thousand-person conversion and are marked `verified_against_archive_excel`.

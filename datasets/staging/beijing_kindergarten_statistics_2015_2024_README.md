# Beijing Kindergarten Statistics (2015–2024): Staging Record

This staging table is a manual visual transcription of Table 20-2, *Kindergarten Basic Conditions (1978–2024)*, in the 2025 Beijing Statistical Yearbook. The original source image is retained at:

`datasets/raw/provincial_china_2015_2025/beijing/2025_statistical_yearbook/C2002_kindergarten_basic_1978_2024.jpg`

Source publisher: Beijing Municipal Education Commission, as identified in the source table.

## Status

The values have passed basic structural and logical checks but remain `requires_second_review`. They are not model-ready and must not be copied into `datasets/processed/` until a second visual transcription or an equivalent independent official tabular source confirms every 2015–2024 value.

## Scope and limitations

- The table supplies kindergarten counts, classes, graduates, new enrolment, enrolled children, teaching staff, and full-time teacher counts.
- It does not provide all PRAI variables, including eligible preschool-age population, licensed places, indoor area, qualified teacher rate, stable public funding share, or unmet demand.
- `full_time_teacher_count` is retained as reported. It is not automatically treated as `fte_teacher_count` until the source definition and any FTE conversion requirement are reviewed.
- No outlier has been removed. Any unusual annual change will be reviewed against source notes and an independent official source during the second-review stage.
